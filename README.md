📘 LeetCode Problem Solutions
This repository contains my solutions to various LeetCode problems, organized by core algorithmic paradigms. The goal of this collection is to strengthen problem-solving skills, understand patterns, and build a solid foundation in Data Structures and Algorithms.
🚀 Topics Covered
🔹 Greedy Algorithms
Greedy algorithms make the locally optimal choice at each step with the hope of finding a global optimum.
Key Concepts:
Interval scheduling
Activity selection
Minimum/maximum optimization problems
Examples:
Jump Game
Gas Station
Assign Cookies
🔹 Dynamic Programming (DP)
Dynamic Programming is used to solve problems by breaking them down into overlapping subproblems and storing results to avoid recomputation.
Key Concepts:
Memoization & Tabulation
1D / 2D DP
State transitions
Examples:
Longest Increasing Subsequence
Coin Change
Knapsack Problem
🔹 Backtracking
Backtracking is used to explore all possible solutions by building candidates step by step and abandoning invalid ones.
Key Concepts:
Recursion
Decision trees
Constraint satisfaction
Examples:
N-Queens
Subsets
Permutations
🔹 Sorting
Sorting is fundamental for optimizing many algorithms and is often used as a preprocessing step.
Key Concepts:
Comparison-based sorting
Stability
Time complexity trade-offs
Algorithms Used:
Merge Sort
Quick Sort
Heap Sort
🔹 Divide and Conquer
This approach divides a problem into smaller subproblems, solves them independently, and combines the results.
Key Concepts:
Recursion
Problem decomposition
Efficient merging
Examples:
Merge Sort
Binary Search
Maximum Subarray 


🛠️ Languages Used
Python, C and CPP
